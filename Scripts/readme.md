
# Scripts

This repository contains Python scripts used for UK Stock market prediction using Causal Inference. The main entry point is `main_pipeline.py`.

## Getting Started

Follow the steps below to clone the repository, install the required dependencies, and run the main pipeline script.

### 1. Clone the Repository

```bash
git clone https://github.com/sjohny-uh/Causal_Inference_Project.git
````

### 2. Install Required Packages

```bash
1) pip install yfinance ta dowhy andas numpy scikit-learn  shap scikit-optimize yfinance scipy statsmodels matplotlib seaborn plotly tqdm
2) Microsoft C++ Build Tools download page - Desktop development with C++
3) $env:INCLUDE="C:\Program Files\Graphviz\include" 
4) $env:LIB="C:\Program Files\Graphviz\lib" 
5) $env:PATH+=";C:\Program Files\Graphviz\bin"
6) python -m pip install pygraphviz 
```

### 3. Run the Main Script

```bash
cd scripts
python main_pipeline.py
```

## Requirements

* Python 3.8 or higher
